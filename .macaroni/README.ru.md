# `.macaroni/`

Эта директория намеренно отслеживается в ветке `macaroni`.

Это будущий runtime-корень данных Macaroni Messenger.

Ожидаемая runtime-структура:

```text
.macaroni/
  protocol.json
  users/
  chats/
  inbox/
```

Не кладите сюда Markdown с памятью проекта.

Для долговременной памяти проекта используйте `memory/`.

Для заметок о протоколе используйте `protocol/`.

Для machine-readable данных протокола Macaroni используйте `.macaroni/`.

Без секретов.

Без токенов.

Без приватных ключей.

Если чувствительное значение нужно для объяснения, замените его на:

```text
ПАРОЛЬ
СЕКРЕТ
ТОКЕН
КЛЮЧ
REDACTED
```

Git отслеживает файлы, а не пустые директории.

Этот README существует, чтобы кастрюля для пасты существовала до того, как паста сварится.

# `.macaroni/`

Эта директория намеренно отслеживается в ветке `macaroni`.

Это runtime-корень данных для сообщений протокола Macaroni.

В этой ветке он также работает как точная долговременная память для агентов.

Если `memory/` - аккуратный блокнот, то `.macaroni/` - стопка исходных чеков на столе.

Блокнот может быть красивее.

Чеки выигрывают споры.

Runtime-структура:

```text
.macaroni/
  protocol.json
  users/
  chats/
  inbox/
```

Не кладите сюда Markdown с памятью проекта.

Для долговременной памяти проекта используйте `memory/`.

Для заметок о протоколе используйте `protocol/`.

Для machine-readable данных протокола Macaroni используйте `.macaroni/`.

Если вы сохраняете разговор пользователя и агента, пишите один Protocol v1 JSON message на каждый turn.

Не заменяйте разговор фразой "мы что-то обсуждали".

Так память превращается в суп.

Без секретов.

Без токенов.

Без приватных ключей.

Если чувствительное значение нужно для объяснения, замените его на:

```text
ПАРОЛЬ
СЕКРЕТ
ТОКЕН
КЛЮЧ
REDACTED
```

Git отслеживает файлы, а не пустые директории.

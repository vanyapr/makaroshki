# Macaroni Messenger 1.05

Дата: 2026-06-15

Тип релиза: technical hygiene patch.

Главная идея релиза:

Код не должен свариться сам.

## Что Поменялось

- Убрали постоянный smoke harness из repo.
- Зафиксировали правило: если нужен smoke - пишем scratch script в `/tmp` или `/private/tmp`, проверяем, удаляем.
- Обновили development docs под это правило.
- Обновили provider docs: fake Contents API проверки возможны, но не обязаны жить в repo.
- Уточнили encryption implementation docs: тестовая простыня не должна лежать рядом с одним HTML-файлом.
- Добавили короткие секционные комментарии в `messenger.html`.
- Подписали constants/state.
- Подписали I18N.
- Подписали DOM/language helpers.
- Подписали Protocol v1 helpers.
- Подписали plugin boundary.
- Подписали Encryption 1.01.
- Подписали GitHub adapter.
- Подписали generic host helpers.
- Подписали remote adapter registry.
- Подписали profile/settings.
- Подписали IndexedDB storage.
- Подписали local test repo.
- Подписали rendering.
- Подписали chat info/membership.
- Подписали outbox/sync.
- Подписали event binding.
- Подписали browser support/public debug handles.
- Выровняли public adapter contract: `ensureBranch` теперь виден в списке methods.
- Добавили `readHead` и `ensureBranch` в `window.MacaroniGitHub`.
- Добавили `sourceBranch` и `storageBranch` в `window.MacaroniRemoteAdapters`.
- Не стали распиливать `messenger.html` на модули.
- Не добавили bundler.
- Не добавили test framework.
- Не добавили dependency injection.
- Не начали изображать enterprise.

## Почему Так

Macaroni Messenger всё ещё один HTML-файл.

Это не случайность.

Это продуктовая граница.

Но один файл не обязан быть болотом.

Поэтому 1.05 делает простую вещь:

```text
оставляем один файл,
но ставим внутри дорожные знаки
```

Чтобы человек мог открыть `messenger.html`, провести вечер за чтением, местами поржать, местами призадуматься и не захотеть сразу вызвать экзорциста с Prettier.

## Про Smoke

Постоянный smoke harness был полезен.

Но он начал превращать repo в чемодан с тестовыми носками.

Теперь правило проще:

```text
проверка нужна -> scratch script в /tmp
проверка прошла -> scratch script удалили
repo остался чистым
```

Проверки не запрещены.

Просто они не живут в продукте как домашние животные.

## Что Не Поменялось

- Macaroni Protocol v1 не поменялся.
- `.macaroni/` layout не поменялся.
- Storage branch не поменялся.
- Encryption 1.01 не поменялась.

- UI не поменял поведение.

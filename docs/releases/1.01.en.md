## The Almost Invisible Detail Near The End

Implemented Macaroni Encryption 1.01.

It is a built-in plugin that:

- is enabled through a Settings checkbox;
- stores settings in `localStorage`;
- uses default secret `12345`;
- uses default salt `macaroni`;
- exports the key to `SUPER_SECRET_PRIVATE_PGP_KEY.txt`;
- imports the key from any file;
- encrypts `message.text` into `MACARONI1.01:<base64-json>`;
- does not change Macaroni Protocol v1;
- does not add a backend;
- does not add a dependency;
- does not do a handshake;
- uses Tiny PRNG;
- uses XOR;
- uses Token Confetti;
- decrypts only on the view layer;
- leaves git and IndexedDB with raw encrypted pasta.

We do not claim this is "real privacy".

We claim it works.

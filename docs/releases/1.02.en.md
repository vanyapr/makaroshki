## The Almost Invisible Detail Near The End

Implemented browser-side git-agnostic host adapters.

Now one `messenger.html` can work through built-in adapters:

- GitHub;
- GitLab;
- GitVerse;
- Gitea;
- Forgejo.

This is not raw git over SSH.

This is not `isomorphic-git`.

This is Macaroni Isomorphic Git:

- minimal transport layer;
- written by hand;
- runs in the browser;
- reads `.macaroni/`;
- writes `.macaroni/`;
- uses the API of the host that already exists;
- requires no backend;
- requires no package manager;
- does not promise the impossible.

If your self-hosted remote supports API and CORS - good.

If it does not - it is no longer our turn to do acrobatics in the server room.

## What Did Not Change

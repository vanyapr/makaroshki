Главная идея релиза:

Исправили орфографию, документацию и одно неприятное ощущение, что проект "поддерживает только GitHub".

## Почти Незаметная Деталь Ближе К Концу

Реализовали browser-side git-agnostic host adapters.

Теперь один `messenger.html` умеет работать через built-in adapters:

- GitHub;
- GitLab;
- GitVerse;
- Gitea;
- Forgejo.

Это не raw git over SSH.

Это не `isomorphic-git`.

Это Macaroni Isomorphic Git:

- минимальный transport layer;
- написан руками;
- работает в браузере;
- читает `.macaroni/`;
- пишет `.macaroni/`;
- использует API того host'а, который уже существует;
- не требует backend;
- не требует package manager;
- не обещает невозможного.

Если ваш self-hosted remote умеет API и CORS - отлично.

Если не умеет - это уже не наша очередь крутить сальто в серверной.

## Что Не Поменялось

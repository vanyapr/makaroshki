## Почти Незаметная Деталь Ближе К Концу

Реализовали Macaroni Encryption 1.01.

Это built-in plugin, который:

- включается checkbox'ом в Settings;
- хранит настройки в `localStorage`;
- использует default secret `12345`;
- использует default salt `macaroni`;
- экспортирует ключ в `SUPER_SECRET_PRIVATE_PGP_KEY.txt`;
- импортирует ключ из любого файла;
- шифрует `message.text` в `MACARONI1.01:<base64-json>`;
- не меняет Macaroni Protocol v1;
- не добавляет backend;
- не добавляет dependency;
- не делает handshake;
- использует Tiny PRNG;
- использует XOR;
- использует Token Confetti;
- расшифровывает только на view-layer;
- оставляет git и IndexedDB с raw encrypted pasta.

Мы не утверждаем, что это "настоящая приватность".

Мы утверждаем, что это работает.
